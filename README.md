# The Connection

Vincent Yen's Spotify-inspired portfolio. The first release includes a responsive application shell, a landing page, a searchable project library, and playlist-style project case studies.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Built with React, TypeScript, Vite, Lenis, GSAP, Vanta, and one adapted React Bits interaction.
